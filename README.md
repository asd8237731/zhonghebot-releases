# MochiBot 发行下载

众合桌面 AI 助手的公开制品仓库。此仓库只提供安装包、签名更新包和更新清单；应用源码保留在私有开发仓库。

请从 [最新发行](https://github.com/asd8237731/zhonghebot-releases/releases/latest) 下载 macOS ARM64 DMG。当前测试包需要 Apple Silicon Mac 和 macOS 12 或更高版本。

首次安装请退出旧版，把完整的 MochiBot.app 拖入“应用程序”。测试包采用 ad-hoc 应用包签名，尚未经过 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

从 0.1.2 起可通过应用内“检查更新”下载并确认安装后续版本。更新包使用独立的签名密钥，应用会核验签名和版本；安装前请完成或停止任务与排队工作。

官网：https://www.zhonghedingfu.com

Homebrew tap 尚未发布。请阅读每次 Release 的已知限制；此仓库不保存用户聊天、账号或密钥。
